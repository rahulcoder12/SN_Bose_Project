Installation Steps

  1. 1

    Download & Extract the ZIP

    Click the "Download Extension ZIP" button above. Once downloaded, right-click the ZIP file and select Extract All (Windows) or double-click (Mac). Remember where you extracted it — you'll need that folder in Step 3.

    💡 Extract to a permanent location (e.g. Documents\enterprise-extension). If you delete the folder later, the extension will stop working.
  2. 2

    Open Chrome Extensions Page

    In Chrome (or Edge / Brave / Arc), navigate to the Extensions manager. You can do this three ways:

    🔒
    chrome://extensions
    ↵
    Or: Chrome menu (⋮) → Extensions → Manage Extensions
  3. 3

    Enable Developer Mode

    On the Extensions page, toggle on Developer mode in the top-right corner. This allows Chrome to load extensions that aren't from the Web Store.

    🛠️ Developer mode
    Load unpacked Pack extension Update
    ⚠️ Chrome will show a "Developer mode extensions" banner on startup — this is normal for sideloaded extensions. Click Cancel to dismiss it.
  4. 4

    Load Unpacked Extension

    Click the "Load unpacked" button (visible after enabling Developer Mode). In the folder picker, navigate to and select the extracted extension folder — the one containing manifest.json.

    📁 enterprise-extension /
    📄manifest.json✓ required
    📄content.js
    📄background.js
    📄register.html
    📄register.js
    📄calibration.html
    📄calibration.js
    ✅ Once loaded, Zero Trust — Enterprise Shield will appear in your extensions list with a shield icon. The extension is now active on all websites.
