Core Features

Authentication That Thinks
Like a Security Expert

Every interaction is silently analysed by an Isolation Forest AI model trained on your unique behavioural fingerprint.

Behavioral Fingerprinting

Continuously captures keystroke timing, inter-key intervals, mouse velocity, acceleration curves, and scroll rhythms to build an invisible biometric profile unique to each user.

Real-Time AI Analysis

Isolation Forest model processes telemetry in under 50 ms and flags anomalies instantly. Alerts your SOC team via webhook the moment a threat is detected.

Zero-Knowledge Auth

Raw biometric data never leaves the session scope. Only statistical vectors are transmitted, keeping all PII fully protected at the client layer.

Live Session Dashboard

Admin console shows all active sessions, identity confidence scores, anomaly flags, and behaviour drift — a live SIEM feed for every user on your platform.

GDPR Compliant

Automatic 24-hour biometric data eviction, parameterised SQL queries, and full audit logging ensure compliance with GDPR, SOC 2, and ISO 27001.

Enterprise REST API

Full REST API with JWT + API-key auth, rate limiting, and WebSocket support. Integrate biometric trust scores directly into your existing auth stack via the client SDK.

The Process

From Install to
Invisible Protection

Four steps and you're protected. The extension handles everything transparently in the background.

  1. Install & Register

    Add the Chrome extension in one click. Create an account and baseline training begins automatically.

  2. Calibration Phase

    Browse naturally for a few minutes. The AI observes your typing cadence, mouse signature, and scroll rhythm.

  3. Continuous Verification

    Every 5 seconds, the AI re-verifies your identity silently. No popups, no re-logins.

  4. SOC Alerting

    Anomalies trigger real-time webhook alerts to your SOC. Review live sessions and suspend threats instantly.

Security Architecture

Built with
Defence-in-Depth

Every layer is hardened. From bcrypt password hashing to parameterised SQL queries, Zero Trust Auth is engineered by security engineers, for security engineers.

  • ✓
    bcrypt (12 rounds) — Maximum-cost password hashing
  • ✓
    JWT Auth — 30-min access tokens + 7-day refresh rotation
  • ✓
    Rate Limiting — 5/min login, 3/min register, 20/min telemetry
  • ✓
    Security Headers — HSTS, X-Content-Type-Options, X-Frame-Options
  • ✓
    Parameterised SQL — Zero SQL injection surface, always parameterised
  • ✓
    Audit Logging — Rotating file handler with full request audit trail
